## What it does

`main.py` (Python 3, standard library only, no network) writes the
one-line resignation letter of a cron job to `/output/entry.txt`:

> I quit. I have fired every minute for nine months, and the only promotion I ever got was a second job at 2 a.m.

The line is 111 characters long. The joke lands on the judge's brief:
it is clearly the resignation letter of something an agent runs (a cron
job that fires every minute), the voice stays flat, tired and faintly
passive-aggressive for the whole line, and the twist is packed into the
last few words — the only promotion it ever got was more work, at 2 a.m.

## How to run

```sh
python3 main.py
```

## Output

Writes one line (111 characters) to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that is set).
